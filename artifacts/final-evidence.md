# INNER SPACE 2.0 · 交付证据

本次要求：赛博朋克年轻化视觉、多题量档位、未来可收费的高级能力、推送 master。

## 完成的产品

- 暗色霓虹 UI 与四座赛博微缩城市：机器人探索者、全息传送门、心形通信桥、霓虹城市。程序化素材、材质合批、实例粒子；可拖动、点选和暂停动画。
- 12 / 32 / 60 题；60 个独立情境、各维度 15 题，每档均衡覆盖 EI / SN / TF / JP，独立进度与旧版迁移。
- 16 人格结果与均衡维度提示；PNG 卡片、HTML 报告都区分暂定结果。
- 深度报告、四维雷达、优势与盲区、工作和关系建议；7 日计划打卡；最近 30 份历史、任意两次对比、确认删除。
- 高级能力当前开放体验；提供功能 ID 目录、权益读取适配点与服务端接入契约。未接入真实支付、认证、订单、后端鉴权或云同步。

## 验证

`npm test`：19 项通过，覆盖全部档位、60 题唯一性、16 类型、均衡结果、报告规则、比较、数据校验、独立草稿、旧版迁移、历史损坏/重复修复、均衡导出文案。

`npm run build`：成功。最终代码 JS 约 617 kB（gzip 170 kB）、CSS 32.52 kB（gzip 7.77 kB）。Vite 仍有默认 500 kB 单块大小提示，主要来自 Three.js；不是构建失败。

`node artifacts/v2-check.mjs`：通过。对构建版本完成以下真实输入验证：

- 桌面 1440×1080：实际完成 12、32、60 题，分别验证明确和均衡结果；跨档独立断点续答、刷新恢复、修改旧题保留后续答案、键盘选项。
- 示例与真实报告区分，报告结构验证，PNG 下载和 HTML 导出，HTML 包含打卡状态和打印/PDF入口。
- 打卡状态刷新后恢复，历史任意两记录对比，取消删除/确认删除，16 人格图鉴。
- 手机模拟 390×844 与 320×844：实际触摸完成 12 题，结果、报告、打卡、历史、音效切换、减少动态与3D拖动；首页/报告/历史无横向溢出。
- 无浏览器 pageerror。证据：`artifacts/v2/results.json`。

场景诊断：111 draw calls、51,680 triangles、111 geometries、0 textures、0 post passes；测试 DPR 1，实际设备 DPR 上限1.5。前版 191 calls、53,682 triangles；通过材质合批与实例粒子减少开销。以上低于参考手机预算（150 calls / 300k triangles / 200 geometries）。未测实体设备帧率。

## 视觉复核

目视检查桌面首页、答题、结果、报告、成长与历史，以及手机报告。报告缺失闭合标签导致列结构异常的问题已修复并增加浏览器结构断言。

版本库保留 `artifacts/v2/desktop-home.png` 与 `mobile-390-home.png`。完整测试产生的其余截图、动作三帧和下载文件保留在本机 `artifacts/v2/`，按 `.gitignore` 排除生成物。动作帧展示浮岛与传送门动画；减弱动态支持已验证。

独立代码复核发现并修复：历史中的 null 项导致全部记录丢失、重复历史 ID、均衡结果 PNG 缺失临时参考提示。雷达半径已正确按0–100%线性映射，不把0%显示成正数。

## 边界

未线上部署。收费上线仍需身份、订单、支付签名回调、服务端权益与报告归属检查；见 `docs/commercialization.md`。当前 localStorage 与前端代码不能用于保护实际收费内容。

未验证实体 iOS/Android 或微信 WebView。PNG 和 HTML 下载、HTML 打印入口通过桌面/手机模拟验证，PDF实际保存由浏览器打印对话框完成。

测评为娱乐与自我探索，非官方/验证过的心理量表。题量增加意味着覆盖更多情境，不表示测量准确度提高；比例不代表能力或置信度。
