# INNER SPACE · 人格宇宙
目标：年轻、多元、适合移动端的 3D MBTI 自我探索游戏。
设计：奶油底色、墨绿字体、四座软陶质感微缩浮岛。使用程序化 Three.js 场景，不依赖外部素材服务。
核心循环：旋转/选择浮岛 → 阅读情境 → 选择最贴近自己的行为 → 收集碎片、进入下一情境 → 12题生成性格卡 → 下载/重新探索。
选择无需限时与对错，避免将速度或技巧误算作人格；动机来自解锁四岛与收集12碎片。退出保留本机进度。重来清空本轮。
场景计划：能量森林(EI)、灵感之境(SN)、共鸣峡谷(TF)、节奏之城(JP)。桌面3D居右，移动端上方，问题浮层不遮挡操作。
输入：鼠标拖动/触摸旋转、点击岛屿预览、按钮答题、键盘操作原生按钮。
实现：Vite + Three.js + 原生 DOM。测评不作诊断，仅呈现本轮选择倾向，16类型均中性描述。
待完成：场景、交互、生产构建、桌面/手机完整流程验证。
