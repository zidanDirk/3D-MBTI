# 两项可玩性升级：竞品调研与实现决策

调研日期：2026-10-08。以作者、发行商的页面及规则为依据；没有使用竞品代码、美术、题库。网页资料分析不等同于长期用户测试，下面的趣味性提升是设计推断，不能声称已提高留存率。

## 现状

当前产品有 12/32/60 题测评、16 个 3D 人格角色、报告与成长记录。测试之后主要是查看和导出，角色没有参与持续目标；重复作答的奖励有限。需要让玩家在半分钟内做有反馈的决定，并给完成测试之后一个自然去处。

## 方案一：霓虹夜航

**承诺**：和人格宇宙居民赶赴流星雨，自己决定这趟夜航怎样结束。

**循环**：阅读眼前事件 → 对照资源和路线作选择 → 看到故事后果与数值变化 → 走到不同场景 → 达成并收藏结局 → 换路线再玩。

- 六次决定、真实分支节点；电量、信号、同行三种资源，成本与条件公开。
- 消耗电量换信号，或慢下来与伙伴合作；部分物品打开后续选项。
- 四种结局，有可达条件与收藏进度；保底收尾避免中途软锁。
- 自动本机存档、继续与重开；路线日志可复盘。奖励是实际持久化结局收藏，而非单次庆祝动画。
- 失败代价为未能获得目标结局，可立即重新规划；无倒计时，不把反应速度当作人格。
- 使用已有 3D 角色作为当场说话者，配合场景名、路线图、资源变化与招呼反馈。

**关卡节奏**：起点选路线 → 不同居民提供资源取舍 → 物品与条件组合 → 收束到发射台 → 选择满足条件的结局。玩家学会先看成本、积累目标资源，再追求不同结局。

## 方案二：双人默契挑战

**承诺**：不是猜你属于哪一类，而是发现“原来你会这样选”。

**循环**：交给 A → A 选自己与预测 B → 隐藏并交给 B → B 选自己与预测 A → 一起揭晓 → 用讨论问题聊一句 → 六回合总结 → 换题包再玩。

- 日常、旅行、脑洞三个原创题包，各六题三选一，约 3–5 分钟。
- 交接幕不显示前一人的答案；选择可修改，提交后才锁定。未选完整不能提交。
- 每题显示真实相同点、双方猜中与否、聊天引导；最终分别汇总同选次数和预测得分。
- 角色可各自选择，仅作形象；分数来自实际答案，不制造 MBTI 配对成功率。
- 双人答案只保存在当前页面内存，离开可暂停返回，刷新即清空；不写入浏览器永久存储或上传。
- 允许随时结束，重开可换题包；不是联网房间，也不假装已经发出邀请。

## 为什么选这两个

分支冒险解决独自玩时的目标、后果与重玩；双人挑战解决和朋友一起玩的悬念与讨论。两者共享已有角色和视觉、能在现有静态 H5 上完整运行，范围可控且可自动验证。没有选择随机抽卡、强制日签或排行榜，因为它们不直接改善当下操作，也缺乏当前账户与服务端支持。

## 验收与后续度量

功能验收：遍历冒险路线证明四结局可达、不能透支、无软锁；双人逐阶段验证未揭晓前不在 UI 暴露答案，得分与记录一致；刷新恢复冒险但不保存双人答案；桌面/320/390px 真实输入；旧测评回归；生产构建和 /mbti/ 子路径。

后续若加入经用户同意的匿名统计，可观察新玩法启动率、完成率、不同结局重玩率和第二个题包启动率。本版本没有接入埋点，不声称已验证业务增长。
